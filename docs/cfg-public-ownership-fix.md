# CFG reuse ownership boundary

Source-only follow-up to main abcf69a0, based on merged compatibility source615e515b. Nothing in this source has been built or tested yet.

Public AbstractCfgCallbackBase.GetControlFlowGraph and TypeInferencePass.ComputeCfg retain their previous owned-result lifetimes. A public getter called after a stock pass has already built a borrowed graph transfers that graph's current cache slot, preserving existing node/annotation identities. Publication is sticky for the callback lifetime so later siblings cannot reset its liveness maps, flow states or lattice buffers. Existing exception types and stack publication order remain unchanged.

Only exact CheckMissingReturn, CheckUnreachableCode, DAE and Coalesce callback instances with the exact same active traversal callback and concrete Compiler borrow the private per-depth CFG cache. Expert wrappers fall back even when their embedded callback base still has a concrete stock self. Instrumentation's existing public getter remains owned. DAE uses independent finder/analysis objects on owned paths; Coalesce allocates independent per-function state there. Default stock paths retain per-depth reuse. Public TypeInference.ComputeCfg allocates independently, while InferScope consumes its private reusable graph before the next scope.

Tradeoff: public/expert paths allocate as before; a callback that publishes any CFG permanently gives up future borrowing. This conservative rule prevents later hidden reset of already retained values without graph cloning or deep-copying arbitrary annotations. No elapsed-time, memory or byte-parity claim is made. Stock activation and semantic controls are unrun.

cfg_public_ownership_test.go uses APIs and fields present in prior fixed1fe, and supplies positive controls for sibling retained CFGs, sequential TypeInference.ComputeCfg results and retained Coalesce analysis/annotation state. They should fail pre-fix615 for the ownership changes, not missing symbols. cfg_private_reuse_activation_test.go intentionally uses new cache fields and is candidate-only: it verifies an actual stock Coalesce traversal still reuses one analysis slot and its private CFG. Existing tests are unchanged. Required validation is stock1fe positive/pre-fix615 negative/candidate positive, then existing targeted/full/race parity and Java artifact gates before timing.
