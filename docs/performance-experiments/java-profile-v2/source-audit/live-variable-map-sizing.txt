Ownership and count:
NodeUtil.AllVarsDeclaredInFunction is a static final class, not a record. Its
constructor is private; its sole construction site is NodeUtil's collection
factory. Its getters merely return the stored ArrayList and LinkedHashMap, with
no override hooks. The returned collections themselves are mutable, not immutable.
The factory appends each encountered Var to the list and puts that Var under its
name in the map. The list length is an upper bound on inserted names; shadowing
can repeat names. For the ordinary unmodified factory result, map.size() is the
exact distinct-name count that addScopeVariables will insert. This avoids
overestimating capacity from duplicate names in the ordered list.

Both in-tree LiveVariablesAnalysis callers use the factory result without
modifying either collection before construction. computeEscaped reads the map
and populates only escaped. A later count mismatch from nonstandard mutation
would affect sizing only; ordinary map insertion would still resize as needed.

assigns the same incrementing index, and overwrites repeated names identically.
The map remains private and is used only through put/get. Reading the ordinary
map size is constant-time and introduces no user callback. Expected-size
construction targets backing-table resizes for large scopes and oversized
default tables for small nonempty scopes; it does not avoid per-entry allocation.
